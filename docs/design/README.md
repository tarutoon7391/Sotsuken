# html — 画面デザイン一式

画面ごとに `番号_画面名/` フォルダ。各フォルダの `index.html` をブラウザで開く（ダブルクリックで動く）。
画面下の暗い「状態」バーで、状態／ロール／スマホ表示を切り替えて確認する。

| フォルダ | 画面 | 担当プロンプト |
|---|---|---|
| `01_ログイン/` | ログイン | 01 |
| `02_会員登録/` | 会員登録（ロール選択） | 02 |
| `03_プロフィール設定/` | プロフィール設定 | 03 |
| `04_クラス一覧/` | クラス一覧（先生／生徒） | 04 |
| `05_クラス詳細/` | クラス詳細（先生／生徒） | 05 |
| `06_先生画面_授業中/` | 先生画面（授業中）※PCのみ | 06 |
| `07_出席一覧/` | 出席一覧・修正 | 07 |
| `08_授業結果/` | 授業結果 | 08 |
| `09_授業待機/` | 授業待機（開始前） | 09 |
| `10_生徒画面_授業中/` | 生徒画面（授業中）基準デザイン | — |
| `12_一時退出中/` | 一時退出中 | 12 |
| `13_授業終了/` | 授業終了 | 13 |
| `14_エラー/` | エラー／権限なし | 14 |

## common/（全画面共通）

- `broadsheet.css` — デザインシステム Broadsheet の変数・部品（唯一のコピー。色・余白はここから取る）
- `screens-01-03.css / .js` — 01〜03 の共通部品
- `screens-04-06.css / .js` — 04〜06 の共通部品（ヘッダー・名前セット・状態切替バー・アイコン・生徒30人モック）
- `common-07-09.css / .js` — 07〜09 の共通部品
- `screens.css`, `demo-state.js` — 10・12〜14 の共通部品

## 決めごと

- 各画面フォルダの中は `index.html` ＋ その画面専用の css / js のみ
- 共通で使うものは `common/` に置き、`../common/〜` で参照する
- 画面間のリンクは `../04_クラス一覧/index.html` のように相対パスで書く

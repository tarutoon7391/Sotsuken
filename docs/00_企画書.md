# 卒業研究 企画書（チーム内共有用）v4

> これはメンバー確認用の資料。発表用の正式書類は別途作成する。

## 1. テーマ

**学校のオンライン授業に特化した、低遅延・双方向ライブ授業アプリ（仮称未定）**

先生が授業を回すために設計されたWebアプリ。配信・チャット・出席・理解度・質問箱・資料表示が
1画面に統合されている。生徒は参加コードでクラスに入り、先生の映像を1秒未満の遅延で視聴しながら、
理解リアクション・質問・確認ボタンで授業に参加する。生徒のカメラ映像は先生にだけ届き、
発表時は先生のスポットライト操作でその生徒だけを全員に表示する。

## 2. なぜこのテーマか

1. **独自性**：汎用配信サービスの縮小版ではなく「授業専用設計」に振り切ることで、
   Zoom/Meet との差別化が明確になる（出席・理解度・質問箱・確認ボタンが標準搭載）
2. **技術的に過去最高に挑戦できる**（WebRTC / SFU / 多人数カメラの購読制御）
3. **発表で伝わるデモ**：会場を「体験用クラス」にし、来場者が生徒として参加できる
4. **本番で安定して動く**（学校ネットワークが本番環境。デモ事故対策を設計段階から組み込む）

## 3. Zoom/Meet との違い（発表で必ず聞かれる）

| 観点 | 汎用会議ツール | 本アプリ |
|---|---|---|
| 出席 | 手作業・別ツール | 自動記録。退出時間の累積が15分を超えると欠課の自動判定、先生が修正可 |
| 理解度 | 挙手や口頭 | 「わかった/わからない/もう一度」をリアルタイム集計 |
| 質問 | チャットに埋もれる | 雑談と分離した質問箱、匿名可、回答済み管理、挙手ボタン |
| 受講確認 | 無し | 確認ボタン（制限時間内に応答） |
| 資料 | 画面共有か別ウィンドウ | 視聴画面の横に資料パネル |
| 視界 | 全員が全員の顔を見る | 生徒同士は見えない。先生だけが全員を見る。発表者のみスポットライト |

## 4. 機能一覧（概要）

| 区分 | 機能 |
|---|---|
| MVP（絶対作る） | アカウント（先生/生徒ロール・バッジ）、クラス作成・参加コード、授業の開始/終了（同時1授業）、低遅延配信、全員カメラON（生徒映像は先生のみ・スポットライト）、出席（一時退出・累積15分ルール）、確認ボタン、理解リアクション＋集計、質問機能（挙手・質問箱・匿名）、チャット（画像/PDF添付）、授業内資料表示 |
| ストレッチ（優先順） | 理解度の時系列グラフ、ミニテスト、復習アーカイブ、課題配布・提出、文字起こし、資料ページ同期、グループワーク部屋分け、アーカイブ前後カット |

詳細は `docs/01_要件定義.md` を参照。

## 5. 技術スタック（概要）

- フロントエンド：HTML / CSS / JavaScript（フレームワーク採用は初回MTGで相談）
- バックエンド：Node.js（Express + Socket.IO）、出席タイマー等のジョブ
- 配信基盤：WebRTC（LiveKit SFU）。生徒映像の購読制御・スポットライトも LiveKit の権限機能で実現
- DB：MySQL ／ インフラ：Railway（＋Volume）＋ SFUサーバー（開発時 LiveKit Cloud → 本番 VPS）、アーカイブは Cloudflare R2
